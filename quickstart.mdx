## Quickstart

Get a private SMASH LEGENDS server running on your Windows machine in under 30 minutes. You will install the .NET 10 SDK, build the server, extract game metadata, patch the official client, and launch the server.

## Prerequisites

<Callout kind="info">

- Windows 10 or 11. The server uses Windows' built-in SQLite through P/Invoke.
- .NET 10 SDK installed.
- Steam installation of SMASH LEGENDS with Steam app ID `1352080` and Unity version `2022.3.62f3`.
- PowerShell 5.1 or later.
- The repository cloned to your local machine.

</Callout>

## Setup steps

<Steps>
  <Step title="Build the server" icon="terminal">

Run the build from the repository root:

```bash
dotnet build SmashLegends.sln -c Release
```

This compiles `SmashLegends.Server`, `SmashLegends.Admin`, and `SmashLegends.Patcher`.

  </Step>

  <Step title="Extract game metadata" icon="package">

The server requires a `metadata.bin` file extracted from your own SMASH LEGENDS installation. Use the tools in `_work/tools/` to extract the file, then place it at `data/masterdata/metadata.bin`.

The file is not committed to the repository. It must come from your own game installation.

  </Step>

  <Step title="Run the setup script" icon="play">

From the `scripts/` directory, run:

```powershell
.\setup-private-server.ps1
```

The script verifies the game build, generates manifests, and prepares the configuration.

  </Step>

  <Step title="Patch the game client" icon="wrench">

Apply the dedicated-server patch and install `local-config.xml`:

```powershell
.\apply-dedicated-server-patch.ps1
```

The patch modifies the official client to redirect to your private server. The patch is hash-verified and fully reversible with `unpatch.ps1`.

  </Step>

  <Step title="Launch the server" icon="server">

Start the HTTP backend:

```powershell
.\run-server.ps1
```

The server listens on port `18080` by default. Start the admin console separately with `admin-console.ps1` when you need administrative controls.

  </Step>

  <Step title="Connect the game client" icon="gamepad">

Launch the patched SMASH LEGENDS client. The client reads `local-config.xml` and connects to your private server.

Press `H` to start a host or `C` to join a development host.

  </Step>
</Steps>
